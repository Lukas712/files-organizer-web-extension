    About

    File Organizer Web Extension automatically organizes downloaded files based on user-defined rules.

    • Version1.0.0
    • GitHub Repository
    • Issues Report a bug
    • LicenseMIT

    Uses Chrome Downloads API and follows its filesystem limitations.

    Help

    How rules work

    Rules are evaluated in order. The first matching rule is applied and stops evaluation.

    Matchers

    • Extension
    • MIME
    • URL
    • Final URL
    • Referrer
    • Filename

    Case-insensitive. Supports wildcards (*) and RegExp. Empty matchers are ignored.

    MIME types

    MIME Description
    application/pdf PDF
    application/zip Archives
    image/png PNG
    image/jpeg JPEG
    audio/mpeg MP3
    video/* Videos

    Wildcards: image/*, */* · MDN reference
